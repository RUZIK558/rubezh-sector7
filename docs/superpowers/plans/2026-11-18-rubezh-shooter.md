# РУБЕЖ // СЕКТОР 7 — план реализации

> **Для исполнителя:** план выполняется нативно в текущей сессии (прямое указание
> `delay` — сделать шутер). Шаги отмечены чекбоксами. Спецификация:
> `docs/superpowers/specs/2026-11-18-rubezh-shooter-design.md`.

**Цель:** собрать законченный волновой FPS «РУБЕЖ // СЕКТОР 7» в Godot 4.7
с моделями Blender, звуком, HUD, меню и пятью волнами.

**Архитектура:** один main-узел `Game` управляет состояниями, арена строится
кодом из GLB-пропсов, игрок/оружие/враги — отдельные сцены с GDScript,
UI строится кодом через общий `ui_theme.gd`, автозагрузки `Settings` и
`AudioManager`.

**Стек:** Godot 4.7.1 (GL Compatibility), Blender 5.2.2 LTS, GDScript,
Python (numpy/Pillow) для текстур и WAV, MCP Blender/Godot.

**Спека:** `docs/superpowers/specs/2026-11-18-rubezh-shooter-design.md`

## Глобальные ограничения

- Рендер: `gl_compatibility`; окно 1600×900, stretch `canvas_items`, aspect `keep`.
- Пути запуска Godot — только `--path '/home/ruzik-admin/Документы/Проект по умолчанию/godot_project'`.
- glTF-материалы только статические (Base Color/Metallic/Roughness), без процедурных нод.
- Все тексты интерфейса — на русском; шрифт Montserrat (Cyrillic).
- Слои: 1 мир, 2 игрок, 3 тела врагов, 4 хитбоксы врагов, 5 снаряды.
- Никаких внешних ассетов; всё генерируется локально.
- Каждая задача заканчивается проверкой в Godot (validate/get_errors/скриншот).

## Review Focus

- Стрельба при пустом магазине/запасе не должна блокировать игру: гарантированный
  дроп патронов, корректный щелчок, отсутствие отрицательных патронов.
- Пауза не должна останавливать UI, но должна останавливать игрока, врагов,
  снаряды и таймеры; повторное Esc не должно ломать состояние.
- Смерть игрока и победа должны срабатывать ровно один раз, без повторного
  показа результатов и без «зависших» врагов.
- Спавн врагов не должен происходить внутри геометрии/игрока; застрявший враг
  обязан применить манёвр, а не стоять.
- Рестарт после поражения/победы должен полностью сбрасывать здоровье, патроны,
  счёт, волну, бочки и подобранные предметы.
