# Скилл «видеть фото» для текстовой модели

Дата: 2026-11-17
Статус: согласовано пользователем («давай, надо чтобы ии которая не видит начала видеть»)

## Зачем

Текущий скилл `image-to-text` читает текст через Tesseract и честно говорит, что не умеет
описывать фото. Пользователь прислал фото кота и попросил, чтобы текстовая модель начала
понимать фотографии. Для этого нужна vision-language модель, которая сначала «посмотрит» на
картинку, а потом отдаст текстовое описание — текстовому ИИ не нужно уметь видеть самому.

## Цели

- Локально, без облачных API: картинка не уходит с машины.
- Скрипт `describe.py` внутри уже существующего скилла `image-to-text`: один вход — картинка,
  два режима — точный текст (Tesseract) и описание сцены (vision-модель).
- Выход — структурированный текст с описанием, а не «сырая» генерация: агент получает
  понятный ему JSON/Markdown и может честно передать пользователю.
- Работа на RTX 4060 Ti (8 ГБ); CPU — запасной путь.

## Не-цели

- Распознавание конкретных людей и биометрия.
- Перепроверка текста через vision-модель: для точных слов остаётся Tesseract.
- Обучение/дообучение моделей.

## Ограничения и находки

- `registry.ollama.ai` недоступен (TLS timeout, curl → 000): `ollama pull moondream` не работает.
- HuggingFace доступен (200); `transformers 5.23` и `torch 2.15+cu132` ставятся на Python 3.15.
- Для image processor SmolVLM обязательны `torchvision` и `Pillow` **внутри .venv** (иначе ValueError).
- transformers 5 использует аргумент `dtype` (не `torch_dtype`); загрузка целиком в fp16 держит пик ~1.2 ГБ VRAM.
- Если VRAM занята (например, игрой), модель частично выгружается на CPU и предупреждает — работает медленнее.
- Модель отвечает по-английски даже на русский вопрос; скилл просит агента перевести, а не выдавать оригинал.
- После инцидента с зависанием ПК (CPU-тест вместе с CS2) добавлены ограничения: torch ≤ 4 потоков,
  `os.nice(10)`, фото ≤ 768 px, отказ от GPU при свободно менее 2 ГБ VRAM. Тяжёлый integration-тест
  по умолчанию выключен (`RUN_VISION_TEST=1`).
- Локальный Ollama содержит только текстовые модели; в LM Studio есть Qwen3.8-27B + mmproj
  (17 ГБ) — на 8 ГБ VRAM непрактично.
- Диск: 861 ГБ свободно; GPU: NVIDIA RTX 4060 Ti.

## Рассмотренные подходы

- **A. SmolVLM-Instruct через transformers (выбран).** ~1.2 ГБ, чатовая модель, умеет русский,
  быстрая на 8 ГБ GPU. Один скрипт, локальный кэш модели.
- **B. Ollama + moondream.** Отпал: реестр недоступен, модель не скачать.
- **C. Локальный Qwen3.8-27B-VL из LM Studio.** Отпал: 17 ГБ и медленный вывод на 8 ГБ VRAM.
- **D. BLIP captioning.** Проще, но даёт короткий Английский заголовок без диалога — слабее A.

## Устройство

```
~/.config/opencode/skills/image-to-text/
  .venv/                          torch + transformers (не коммитится)
  scripts/describe.py             CLI: IMAGE → Markdown/JSON описание
  image_to_text/vision.py         загрузка модели, запрос, нормализация ответа
  tests/test_vision.py            тесты протокола/формата на заглушках
  SKILL.md                        обновлён: когда фото, когда Tesseract
```

Модель кэшируется в `~/.cache/huggingface`, в каталоге скилла не лежит.

### Контракт `scripts/describe.py`

```
describe.py IMAGE [--question "Что здесь?"] [--json] [--model HuggingFaceTB/SmolVLM-Instruct]
                 [--max-tokens 200] [--cpu]
```

Выход (JSON): `{image, model, device, description: str, details: [str], confidence: clear|likely|uncertain, warnings: [str]}`.
Markdown: `*Видение*` + описание + список деталей + `"не уверен"` рядом с нечёткими формулировками.

### Правила

- Модель грузится лениво, один раз на процесс; при повторных вызовах в той же сессии кэшируется.
- Если не хватает VRAM — fallback на CPU с предупреждением в `warnings`.
- Модель может ошибаться: скрипт не выдаёт конкретные имена/даты/марки без явной оговорки.
- skl `(clear/likely/uncertain)` сохраняется как и в OCR-отчёте.

## Проверка

- Юнит-тесты на подменённом процессоре/модели: формат JSON, обрезка мусора, путь CPU, обработка пустого ответа.
- Реальный прогон на фото кота и на скриншоте: описание должно называть кота и не выдумывать текст.
- Регрессия: 73 существующих теста и бенч WER остаются зелёными.
