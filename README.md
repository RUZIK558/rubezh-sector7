# РУБЕЖ // СЕКТОР 7

Wave-based FPS на Godot 4.7.1 (GL Compatibility). Русскоязычный интерфейс,
20 волн, магазин улучшений между волнами, боссы, процедурная анимация врагов.

## Возможности

- 20 волн, боссы на 5/10/15/20 (Титан, МК-II, МК-III, Титан-Омега).
- Три слота оружия: АК-47, пистолет PM-9, боевой нож «Клин».
- Бросок ножа: ПКМ в прицел с отпусканием, или V (КД 6 с, урон как у ближнего боя). Гранаты: G (2 штуки, КД 4 с).
- Магазин квартирмейстера между волнами: патроны, аптечка, бронепластина,
  урон, расширенный магазин, заточка ножа.
- Арена 64×56 м с укрытиями, вышками, цистернами, радаром и взрывными бочками.
- Все модели сделаны в Blender, все текстуры и звуки сгенерированы локально.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Прыжок | Space |
| Присесть | Ctrl |
| Спринт | Shift |
| Огонь | ЛКМ |
| Прицел | ПКМ |
| Перезарядка | R |
| Смена оружия | 1–3 или колесо мыши |
| Бросок ножа | ПКМ (прицел+отпускание) / V |
| Граната | G |
| Пауза | Esc |

## Запуск из исходников

Откройте `godot_project` в Godot 4.7.1 и запустите `scenes/game.tscn`
(назначена главной сценой).

## Готовые сборки

## Структура

- `godot_project/` — проект Godot (сцены, скрипты, ассеты)
- `tools/` — Blender-генераторы моделей и генераторы текстур/звуков
- `docs/` — дизайн-документ и план реализации
